# Nature-ready Figure Contract

Use this reference whenever the target is Nature or the user asks for Nature-like publication standards. It summarizes the official Nature research figure guide; it is not a claim that all Nature-family titles use one visual template.

## Non-negotiable Baseline

| Area | Default in this skill | Rationale |
|---|---|---|
| Font | Editable Arial/Helvetica; Liberation Sans fallback | Nature requests standard sans-serif, editable text. |
| Type size | Routine text 5–7 pt; panel labels 8 pt bold lowercase | Match Nature's stated minimum, maximum, and panel-label convention at final print size. |
| Axes | Keep axes, ticks, and units in parentheses | Required for interpretable graphs. |
| Palette | Accessible semantic colours plus shape/line redundancy | Nature requires accessible colour use and points authors to colour-blindness guidance. |
| Grid and decoration | No background grid, shadows, patterns, or decorative icons by default | These reduce data-to-ink ratio and are explicitly discouraged. |
| Text colour | Near-black labels with coloured keys, not coloured text | Coloured text is discouraged in the official guide. |
| Export | RGB, editable PDF/SVG linework, embedded TrueType, 450 dpi raster proof | Preserve editability and high-quality raster content. |

## Dimensions and Hierarchy

1. Choose 89 mm for a single-column figure or 183 mm for a double-column figure before selecting font sizes.
2. Allocate visual prominence to the panel that carries the central claim; do not make every panel equally dominant by default.
3. Use one semantic palette per figure. Add only one accent role and keep category colours stable across panels.
4. Place legends outside data whenever direct labels cannot replace them.
5. Export once in vector form and inspect the 450 dpi raster proof at final physical size.

## Prohibited Shortcuts

- Do not rasterize vector text or outline fonts.
- Do not use red versus green as the only meaningful distinction.
- Do not use a rainbow colormap, default categorical palette, drop shadow, patterned fill, or decorative background.
- Do not hide units, remove ticks, or place labels over dense data.
- Do not enlarge a low-resolution image after export; regenerate it from source instead.
