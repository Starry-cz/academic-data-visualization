# Visual Style System: Nature-ready Evidence Design

本技能的默认视觉语言遵循 Nature 的可读性与可编辑性要求：白底、标准无衬线字、色盲安全语义色、细而可见的轴线，以及紧凑但不拥挤的多面板结构。目标不是模仿某一期刊的“装饰风”，而是让读者先看到结论，再读取证据。

## 1. 视觉层级

1. **核心证据**：蓝色 `#0072B2` 或单一朱红 `#D55E00` 强调，拥有最高对比度。
2. **支持证据**：蓝绿、橙色、紫色；用透明度而非相近的新颜色建立层级。
3. **结构信息**：细轴线、刻度、必要的参考线与白色分隔线。
4. **背景信息**：中性灰 `#999999` 或低透明度点，永远不与核心结论争夺注意力。

## 2. 图型规则

| 图型 | 优先做法 | 避免 |
|---|---|---|
| 散点 / PCA | 小点（alpha 0.25–0.55）+ 细椭圆或质心；只标注关键组 | 大而不透明的点、每点都写标签 |
| 柱状 / 森林图 | 水平排序、原始点或区间、0.6 pt 轴线与淡色参考线 | 厚描边、背景网格、无原始数据的均值柱 |
| 密度 / 山脊 / 小提琴 | 色盲安全填充 + 深色轮廓 + 原始点或中位数 | 过强渐变、填满整页的实心色 |
| 热图 / 相关矩阵 | 发散色以零为中点；白色格线；仅在重点格标数值 | 彩虹色图、所有格都加粗文字 |
| 折线 / 时间序列 | 主线 1.0–1.2 pt，辅助线灰化；置信带 alpha 0.18–0.35 | 每条线都高饱和、图例遮挡曲线 |
| 多面板 | 证据有主次时设置英雄面板；平行证据使用等权网格；全图共享色义和字号 | 无依据地放大某面板、每个面板各用一套配色 |

## 3. 出图前快速检查

- 将图缩到论文栏宽时，核心结论是否仍可在 3 秒内被识别？
- 朱红强调是否只指向一个需要读者注意的对象？
- 去色后，线型、形状、排序或文字是否仍能区分关键组？
- 是否保留了轴线、刻度和单位，并移除了没有解释价值的背景网格、图例和统计标记？
- 所有常规文字是否为 5–7 pt、所有面板标签是否为 8 pt 粗体，且没有描边文字？
