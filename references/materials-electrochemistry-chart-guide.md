# 材料表征与电化学图表指南

本指南用于路由 XPS、XANES、EXAFS 与电化学性能图。它补充通用图表契约，不替代具体实验方法、仪器校准或统计报告。

## 1. 参考图中的图型识别

| 面板结构 | 规范化图型 | 注册状态 | 核心证据 |

| XPS 高分辨谱、背景、总拟合与组分峰 | `xps-peak-deconvolution-plot` | 生产模板 | 化学态峰位、面积、峰宽和拟合残差 |

| EXAFS 傅里叶变换幅值 | `exafs-fourier-transform-spectrum` | 可复用模式 | R 空间配位壳层 |

## 2. XPS 峰拟合

生产图必须同时保留：

- 原始或经明确处理的观测谱；
- 总拟合曲线；
- 背景曲线；
- 每个化学组分峰；
- 样品、能区、峰归属和必要的拟合指标。

在图注或方法中报告能量校准、背景模型、峰形、峰宽与峰位约束、面积计算和拟合软件。不能仅凭“峰看起来合理”决定峰数，也不能隐藏残差或不利区间。跨样品比较时保持相同能区、方向、归一化定义与组分颜色语义。

## 3. XANES 与 EXAFS

XANES 比较必须说明能量校准、预边/后边归一化和参考标准。微小吸收边位移只有在校准误差小于声称差异时才可解释。

FT-EXAFS 与 R 空间拟合必须报告：

- `k` 权重、`k` 范围与窗函数；
- `R` 拟合范围、散射路径和相移处理；
- 独立点数、自由参数、参数不确定性与拟合优度；
- 实验谱、拟合谱以及可审查的残差。

WT-EXAFS 必须声明小波类型及参数、`k/R` 范围和窗函数。二维投影是定量读取的主视图；3D 表面仅作为结构辅助，不得用透视遮挡替代二维证据。比较多个样品时必须共享变换参数和色阶。

## 4. 电化学曲线

CV 数据按采集顺序连接，不能先按电位排序。报告扫描速率、循环编号、参比电极、电位窗口，以及电流是原始值还是按面积/质量归一化。

GCD、倍率和长循环图必须报告活性物质量或面积、测试电流密度、截止电压、循环选择规则和容量分母。不要只挑选最稳定的区间，也不要隐藏早期活化、异常循环或失效。

双 Y 轴只有在两个量共享同一循环观测、单位清楚且不会制造虚假同步时才可使用；否则拆为上下对齐的共享 X 轴面板。库仑效率常接近 100%，其窄范围变化不得通过截断轴夸大。

## 5. 动力学与贡献分解

- `b` 值图：仅对严格正值取对数；预先声明拟合范围；报告斜率置信区间、样本数与回归诊断。
- 动力学等高图：披露网格化、插值和平滑方法；不得在观测范围外外推色块；保留等值线作为颜色冗余。
- 电容/扩散贡献图：每个扫描速率的组成应闭合到 100%；报告分解模型、拟合步骤和不确定性。
- 扩散系数曲线：披露计算公式、脉冲协议、几何参数和误差传播；不能对非正值直接取对数。

## 6. 三维性能对比

三维散点容易发生遮挡、视角依赖和距离误判。若三维位置本身不是结论，优先使用二维分面、气泡散点或平行坐标。保留三维图时：

- 给出单位、观察视角和透明度规则；
- 使用标记形状或直接标签，而非只靠颜色；
- 为关键比较提供二维投影、数据表或补充材料；
- 不使用透视、相机角度或轴范围夸大“领先”距离。

## 7. 最低交付要求

所有图均执行数据契约、统计/方法审阅、视觉审阅和导出审阅。生产模板还必须交付 Python 脚本、PNG 预览、SVG/PDF 矢量主文件、`asset.yaml`，并通过 RGB 与灰度证明。
