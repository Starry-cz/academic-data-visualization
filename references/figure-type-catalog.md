# 图表类型决策目录

用于“该画什么图”“还能补哪些图”“这张图是否适合论文 / 工作汇报”的选择阶段。它是主流静态数据图表的可执行分类，而不是声称存在一个可以穷尽的“全部图表类型”清单。

## 使用规则

1. 先确定读者需要比较、分布、关系、结构、流程、空间还是预测性能；不要从图名反推问题。
2. 优先选择编码通道少、读者熟悉、能保留原始证据的图型；同一问题不要并列多个语义重复的图。
3. 图型状态分为：`生产模板`（已有 `assets/figures/` 脚本）、`可复用模式`（已有经审查的视觉与选图规则）、`按需实现`（选择规则已覆盖，但需按数据与依赖生成脚本）。
4. 若用户要求地图、树、基因组轨道、空间组学或交互仪表盘，先确认坐标 / 拓扑 / 注释数据和运行依赖；不可用外形相似的普通图替代。

> 覆盖声明：图型目录列出的是可支持的**选图路径**，不是“每一项都有独立缩略图或现成脚本”的承诺。只有标为“生产模板”的项目可直接复用；其余项目先按数据契约、依赖和终稿尺寸实现，再进入四轮 QA。

## 一览：按信息任务选图

| 信息任务 | 首选图型 | 常见替代 / 补充 | 关键约束 |
|---|---|---|---|
| 类别比较、排序 | 点图、棒棒糖、水平柱、分组柱、哑铃图 | 坡度图、帕累托、瀑布图 | 小样本优先原始点与区间，不只画均值柱 |
| 连续变化、时间进程 | 折线、点线、阶梯图、置信带 | 面积 / 堆叠面积、控制图、甘特图 | 只有有序的时间或剂量才连线 |
| 分布与离散程度 | 原始点、箱线、小提琴、雨云、直方图 | KDE、ECDF、蜂群、QQ 图、山脊图 | 小样本必须显示个体点；避免只用柱形替代分布 |
| 两变量与回归 | 散点 + 拟合、边际密度、六边形 / 二维直方 | 气泡、Bland–Altman、连接散点 | 避免用相关图暗示因果；说明拟合与不确定性 |
| 多变量结构与降维 | 相关矩阵、散点矩阵、PCA / RDA / UMAP | 平行坐标、三元图、载荷 / 双标图 | 说明标准化、降维参数与解释方差 |
| 矩阵、模式和注释 | 聚类热图、相关矩阵、注释热图、日历热图 | 马赛克图、点阵热图、稀疏矩阵 | 连续量用感知均匀色阶；中心值与缺失值要明确 |
| 效应量与不确定性 | 森林图、系数 / 点须图、误差线、漏斗图 | 配对变化图、区间条 | 报告效应量和置信区间，不只报告 p 值 |
| 预测 / 分类模型 | ROC、PR、校准曲线、混淆矩阵 | 特征重要性、SHAP、决策曲线 | 类别不平衡时优先 PR 与校准，不只用 AUROC |
| 差异表达与组学 | 火山图、MA 图、Manhattan、基因点图 | OncoPrint、基因组轨道、富集气泡图 | 阈值、校正方法、基因标注与多重检验必须可见 |
| 集合、流程与层级 | UpSet、Sankey / alluvial、网络图、树状图 | Venn / Euler、树图、旭日图、弦图 | 集合多于 3 个用 UpSet；流向宽度必须有数值含义 |
| 空间与地理 | 分级设色图、比例符号图、空间热图 | 等值线、栅格图、流向图 | 需要坐标系、地图边界与空间尺度；避免误导性面积编码 |
| 项目、运营与业务 | 甘特、漏斗、子弹图、KPI、帕累托 | 控制图、队列 / 留存热图、瀑布图 | 仪表盘用于监测；论文主图避免堆砌 KPI 卡片 |

## 图型清单

### 1. 比较、排序与组成

| 图型 | 适合回答 | 状态 |
|---|---|---|
| 原始点 / 条带 / 抖动点 | 每组个体值如何分布 | 可复用模式 |
| 点图、棒棒糖、水平柱 | 谁更高、排序如何 | 可复用模式 |
| 分组柱、区间柱、配对柱 | 组别 × 条件的差异 | 生产模板 |
| 堆叠 / 100% 堆叠 / 发散堆叠 | 总量与组成比例 | 可复用模式 |
| 哑铃图、坡度图 | 两个时间点或条件之间如何改变 | 可复用模式 |
| 瀑布图、帕累托图 | 增减贡献与重点类别 | 可复用模式 |
| 子弹图、KPI、表格内迷你图 | 目标完成度与日常监测 | 按需实现 |

## 选择时必须拦截的模式

- 小样本的均值柱图：改为原始点 + 区间，或箱线 / 小提琴。
- 3 个以上集合的 Venn：改为 UpSet。
- 不平衡分类只报 AUROC：同时给出 PR 与校准。
- 相关关系被叙述为因果：补研究设计或因果图，不用连线暗示。
- 多变量组成使用饼图：优先 100% 堆叠、点图或 treemap；饼图仅限极少且差异明显的部分。
- 地图没有标准化分母、投影或空间尺度：先补元数据，不能直接绘制。
