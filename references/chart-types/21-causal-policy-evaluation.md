# 因果推断与政策评估 / Causal Inference and Policy Evaluation

> 本文件由 `scripts/generate_chart_catalog.py` 从 `chart-registry.yaml` 生成；不要手工编辑。

## 类别用途

用于路由“因果推断与政策评估”相关研究问题。先核对数据契约，再按实现状态决定复用或新实现。

## 选择总则

1. 先确认研究问题、观测单位和必需变量；不得从图名反推数据。
2. `生产模板` 才能直接进入资产复用流程；其余状态仍需按数据实现并完成四轮 QA。
3. 优先保留原始证据、效应量和不确定性，不用装饰性编码替代统计信息。

## 图型详细条目

### 因果有向无环图（Causal DAG）

- **Canonical ID**：`causal-dag`
- **别名**：causal diagram
- **适合回答**：研究对象在处理效应、反事实趋势与识别假设方面呈现什么结构或差异？
- **定义**：因果有向无环图用于表达处理效应、反事实趋势与识别假设，其核心视觉编码是趋势、间断或因果边。
- **必需数据**：treatment；time；outcome
- **可选数据**：group；label；uncertainty
- **观测单位**：个体、组或时间点
- **推荐编码**：趋势、间断或因果边
- **适用条件**：数据契约能够支持处理效应、反事实趋势与识别假设；视觉编码与研究问题一致
- **不适用条件**：缺少图型必需变量；仅因外形相似而替代领域专用图
- **统计与不确定性**：明确中心、效应量或模型量的定义；有推断性结论时报告与设计匹配的区间或变异
- **样本量与分布要求**：由统计估计、分组数量与目标结论共同决定；小样本必须显示个体证据。
- **轴、尺度与变换**：单位、尺度与变换必须在轴或图注中说明；预先声明且可追溯的标准化、对数或比例变换
- **禁止变换**：为强化视觉信号而改变数值；未披露的筛选、截断或重排
- **颜色、灰度与无障碍**：使用语义稳定且色盲安全的颜色，并保留灰度可辨识性；关键比较使用形状、线型、标签、位置或顺序作为冗余编码
- **标注规则**：只标注支持核心结论所需的对象、阈值与统计信息
- **常见投稿风险**：样本量或不确定性表达不足；把相关或描述性结构误写为因果
- **实现状态**：`on_demand`
- **可复用资产**：无现成资产
- **后端与依赖**：python；r
- **复用限制**：复用前核对数据结构、观测单位、统计语义和输出尺寸
- **替代 / 补充图型**：regression-discontinuity-plot；synthetic-control-plot；interrupted-time-series
- **QA 规则**：AP-1-no-default-palette；VI-2-redundant-encoding；VV-6-grayscale-proof

- **适用条件**：数据契约能够支持处理效应、反事实趋势与识别假设；视觉编码与研究问题一致
- **不适用条件**：缺少图型必需变量；仅因外形相似而替代领域专用图
- **统计与不确定性**：明确中心、效应量或模型量的定义；有推断性结论时报告与设计匹配的区间或变异
- **样本量与分布要求**：由统计估计、分组数量与目标结论共同决定；小样本必须显示个体证据。
- **轴、尺度与变换**：单位、尺度与变换必须在轴或图注中说明；预先声明且可追溯的标准化、对数或比例变换
- **禁止变换**：为强化视觉信号而改变数值；未披露的筛选、截断或重排
- **颜色、灰度与无障碍**：使用语义稳定且色盲安全的颜色，并保留灰度可辨识性；关键比较使用形状、线型、标签、位置或顺序作为冗余编码
- **标注规则**：只标注支持核心结论所需的对象、阈值与统计信息
- **常见投稿风险**：样本量或不确定性表达不足；把相关或描述性结构误写为因果
- **实现状态**：`on_demand`
- **可复用资产**：无现成资产
- **后端与依赖**：python；r
- **复用限制**：复用前核对数据结构、观测单位、统计语义和输出尺寸
