# 复合图与高级科研图形 / Composite and Advanced Scientific Figures

> 本文件由 `scripts/generate_chart_catalog.py` 从 `chart-registry.yaml` 生成；不要手工编辑。

## 类别用途

用于路由“复合图与高级科研图形”相关研究问题。先核对数据契约，再按实现状态决定复用或新实现。

## 选择总则

1. 先确认研究问题、观测单位和必需变量；不得从图名反推数据。
2. `生产模板` 才能直接进入资产复用流程；其余状态仍需按数据实现并完成四轮 QA。
3. 优先保留原始证据、效应量和不确定性，不用装饰性编码替代统计信息。

## 图型详细条目

### 非对称多面板图（Asymmetric Multipanel Figure）

- **Canonical ID**：`asymmetric-multipanel`
- **别名**：无
- **适合回答**：研究对象在多证据整合、三维或高级结构方面呈现什么结构或差异？
- **定义**：非对称多面板图用于表达多证据整合、三维或高级结构，其核心视觉编码是面板层级、三维位置或复合编码。
- **必需数据**：component_data
- **可选数据**：group；label；uncertainty
- **观测单位**：面板、体素或多维对象
- **推荐编码**：面板层级、三维位置或复合编码
- **适用条件**：数据契约能够支持多证据整合、三维或高级结构；视觉编码与研究问题一致
- **不适用条件**：缺少图型必需变量；仅因外形相似而替代领域专用图
- **统计与不确定性**：明确中心、效应量或模型量的定义；有推断性结论时报告与设计匹配的区间或变异
- **样本量与分布要求**：由统计估计、分组数量与目标结论共同决定；小样本必须显示个体证据。
- **轴、尺度与变换**：单位、尺度与变换必须在轴或图注中说明；预先声明且可追溯的标准化、对数或比例变换
- **禁止变换**：为强化视觉信号而改变数值；未披露的筛选、截断或重排
- **颜色、灰度与无障碍**：使用语义稳定且色盲安全的颜色，并保留灰度可辨识性；关键比较使用形状、线型、标签、位置或顺序作为冗余编码
- **标注规则**：只标注支持核心结论所需的对象、阈值与统计信息
- **常见投稿风险**：样本量或不确定性表达不足；把相关或描述性结构误写为因果
- **实现状态**：`reusable_pattern`
- **可复用资产**：无现成资产
- **后端与依赖**：python；r
- **复用限制**：复用前核对数据结构、观测单位、统计语义和输出尺寸
- **替代 / 补充图型**：three-dimensional-surface；three-dimensional-vector-field；grand-tour
- **QA 规则**：AP-1-no-default-palette；VI-2-redundant-encoding；VV-6-grayscale-proof

### 柱线组合图（Bar and Line Composite Chart）

- **Canonical ID**：`bar-and-line-composite-chart`
- **别名**：无
- **适合回答**：如何用柱线组合图可靠回答“整合多个证据层、图型或模态形成复合科研图”这一研究问题？
- **定义**：柱线组合图用于整合多个证据层、图型或模态形成复合科研图，其视觉编码和统计解释必须与数据契约一致。
- **必需数据**：multiple_evidence_layers
- **可选数据**：shared_scale；panel_label；annotation
- **观测单位**：面板、图层、模态或证据模块
- **推荐编码**：面板布局与跨面板对齐；共享尺度和阅读顺序必须明确
- **适用条件**：数据结构能够支持整合多个证据层、图型或模态形成复合科研图；视觉编码与研究问题和统计方法一致
- **不适用条件**：缺少图型必需变量或领域对象；仅因外形相似而替代语义不同的专业图
- **统计与不确定性**：明确图中统计量、模型输出或聚合量的定义；有推断性结论时报告与研究设计匹配的不确定性
- **样本量与分布要求**：由研究设计、估计稳定性与目标结论共同决定；小样本应保留个体证据。
- **轴、尺度与变换**：单位、尺度、坐标系和变换必须在轴或图注中说明；仅使用预先声明、可复现且不改变结论含义的数据变换
- **禁止变换**：为强化视觉信号而修改数值；未披露的筛选、截断、平滑或重排
- **颜色、灰度与无障碍**：使用感知合理、色盲安全并可灰度辨识的配色；关键结论使用位置、形状、线型、标签或顺序进行冗余编码
- **标注规则**：只标注支持核心结论所需的对象、阈值、事件和统计信息
- **常见投稿风险**：数据契约、统计方法或样本量披露不足；使用装饰性编码、误导尺度或把描述性结构写成因果结论
- **实现状态**：`on_demand`
- **可复用资产**：无现成资产
- **后端与依赖**：无
- **复用限制**：必须根据真实数据、终稿尺寸和目标期刊重新实现并完成四轮 QA
- **替代 / 补充图型**：dot-plot；interval-plot
- **QA 规则**：检查数据契约、尺度、颜色、标注、可访问性和导出文件

- **轴、尺度与变换**：单位、尺度、坐标系和变换必须在轴或图注中说明；仅使用预先声明、可复现且不改变结论含义的数据变换

- **颜色、灰度与无障碍**：使用感知合理、色盲安全并可灰度辨识的配色；关键结论使用位置、形状、线型、标签或顺序进行冗余编码
- **标注规则**：只标注支持核心结论所需的对象、阈值、事件和统计信息
- **常见投稿风险**：数据契约、统计方法或样本量披露不足；使用装饰性编码、误导尺度或把描述性结构写成因果结论

### 体渲染（Volume Rendering）

- **Canonical ID**：`volume-rendering`
- **别名**：体渲染图
- **适合回答**：研究对象在图像结构、通道与空间定量方面呈现什么结构或差异？
- **定义**：体渲染用于表达图像结构、通道与空间定量，其核心视觉编码是像素位置、强度与标注。
- **必需数据**：image；measurement
- **可选数据**：group；label；uncertainty
- **观测单位**：图像、视野或样本
- **推荐编码**：像素位置、强度与标注
- **适用条件**：数据契约能够支持图像结构、通道与空间定量；视觉编码与研究问题一致
- **不适用条件**：缺少图型必需变量；仅因外形相似而替代领域专用图
- **统计与不确定性**：明确中心、效应量或模型量的定义；有推断性结论时报告与设计匹配的区间或变异
- **样本量与分布要求**：由统计估计、分组数量与目标结论共同决定；小样本必须显示个体证据。
- **轴、尺度与变换**：单位、尺度与变换必须在轴或图注中说明；预先声明且可追溯的标准化、对数或比例变换
- **禁止变换**：为强化视觉信号而改变数值；未披露的筛选、截断或重排
- **颜色、灰度与无障碍**：使用语义稳定且色盲安全的颜色，并保留灰度可辨识性；关键比较使用形状、线型、标签、位置或顺序作为冗余编码
- **标注规则**：只标注支持核心结论所需的对象、阈值与统计信息
- **常见投稿风险**：样本量或不确定性表达不足；把相关或描述性结构误写为因果
- **实现状态**：`on_demand`
- **可复用资产**：无现成资产
- **后端与依赖**：python；r；calibrated image data
- **复用限制**：复用前核对数据结构、观测单位、统计语义和输出尺寸
- **替代 / 补充图型**：microscopy-image-plate；pathology-image-plate；colocalization-plot
- **QA 规则**：AP-1-no-default-palette；VI-2-redundant-encoding；VV-6-grayscale-proof
